# CodeMif - Learn to Code, Build Your Future

Status: **Tahap 1** (arsitektur, database, koneksi PDO). README lengkap dibuat di Tahap 8.

## Pasang cepat (XAMPP)
1. Nyalakan Apache dan MySQL di XAMPP Control Panel.
2. Salin folder `codenexa` ke `C:\xampp\htdocs\`.
3. Buka phpMyAdmin (`http://localhost/phpmyadmin`) > tab **Import** > pilih `database/schema.sql` > Go.
4. Impor `database/seed.sql` dengan cara yang sama.
5. Saat pengguna membuka **Jelajahi Kursus**, aplikasi otomatis menambahkan kursus CSS, JavaScript, PHP Native, dan Python serta menyiapkan 50 tahap untuk kursus HTML Dasar, CSS, JavaScript, PHP Native, dan Python. Materi memiliki contoh kode untuk diketik, latihan, dan tugas proyek akhir bertahap berupa website mini. Progres materi yang sudah ada tetap terhubung; kursus yang sebelumnya selesai kembali aktif sampai seluruh 50 tahap diselesaikan. Pastikan kategori awal dari `database/seed.sql` sudah tersedia. Alternatifnya, impor `database/seed_learning_paths.sql` melalui phpMyAdmin untuk menambahkan kursus CSS, JavaScript, PHP Native, dan Python.
6. Jika database CodeMif sudah dibuat sebelumnya, jalankan migrasi yang diperlukan melalui phpMyAdmin: `database/migrate_lesson_approval.sql`, `database/migrate_lesson_submissions.sql`, `database/migrate_practice_code.sql`, `database/migrate_learning_activity.sql`, `database/migrate_super_admin.sql`, `database/migrate_school_admins.sql`, `database/migrate_school_classes.sql`, `database/migrate_school_course_visibility.sql`, dan `database/migrate_student_grade_level.sql`. Migrasi terakhir menambahkan pilihan tingkat X, XI, XII pada pendaftaran dan menampilkan tingkat siswa di daftar akun Admin Sekolah.
7. Salin `.env.example` menjadi `.env`, lalu sesuaikan `DB_USER` dan `DB_PASS` dengan MySQL Anda.
8. Untuk membuat akun Super Admin pertama, jalankan skrip CLI `scripts/create_super_admin.php` setelah migrasi. Set `CODEMIF_SUPER_ADMIN_PASSWORD` hanya sementara di environment terminal sebelum menjalankan skrip; skrip tidak menimpa akun `admin` yang sudah ada dan hanya menyimpan hash password. Username akun adalah `admin`, nama lengkapnya `Miftah`, dan password wajib diganti saat login pertama. Email bootstrap menggunakan alamat nonaktif `admin@codemif.invalid`.
9. Buka `http://localhost/codenexa/` dan pastikan semua baris pada halaman cek bernilai hijau.

Menu **Kelola Admin Sekolah** hanya tampil untuk Super Admin. Menu tersebut membuat satu sekolah dan akun `school_admin` terkait dalam satu transaksi, dengan username unik dan password awal yang harus diganti saat login. Super Admin dapat memperbarui nama sekolah dari daftar sekolah; sekolah baru muncul pada pilihan pendaftaran setelah dibuat. Dari daftar akun admin, Super Admin juga dapat memilih **Hapus sekolah** untuk menghapus permanen sekolah tersebut beserta seluruh akun Admin Sekolah dan siswa, kelas, progres, dan riwayat belajar terkait; tindakan ini memerlukan konfirmasi dan tidak dapat dibatalkan. Jika akun Admin Sekolah dinonaktifkan, sekolahnya tidak muncul di pilihan pendaftaran dan pilihan kelas; sekolah akan tersedia kembali setelah ada Admin Sekolah aktif. Formulir pendaftaran menyegarkan daftar sekolah dan kelas otomatis setiap 20 detik, saat tab kembali aktif, dan setelah pengguna menutup pilihan sekolah. Admin sekolah diarahkan ke halaman khusus dan tidak mendapat akses ke panel admin global. Di Panel Admin Sekolah, admin dapat membuat kelas (misalnya PPLG1 dan PPLG2), menonaktifkan atau mengaktifkan kelas, memilih kursus yang ditampilkan atau disembunyikan khusus bagi siswa sekolahnya, dan membuka halaman daftar akun melalui tautan **Lihat akun** pada baris kelas. Pengaturan kursus sekolah tidak mengubah pengaturan sekolah lain; kursus yang dinonaktifkan Super Admin tetap tidak tersedia. Jalankan migrasi `database/migrate_school_course_visibility.sql` jika memakai database lama. Pada akun kelas, admin dapat menonaktifkan/mengaktifkan akun siswa atau menghapusnya secara permanen; penghapusan juga menghapus progres dan riwayat belajar akun tersebut dan memerlukan konfirmasi. Dari akun kelas, admin dapat membuka **Lihat hasil** untuk meninjau kiriman praktik milik satu siswa saja; setiap kiriman ditampilkan satu per satu dan dapat disetujui atau diminta diperbaiki dengan catatan. Hak Admin Sekolah dibatasi ke akun siswa di sekolahnya, sedangkan Admin/Super Admin dapat mengelola akun pengguna dari Panel Admin. Akun yang dinonaktifkan tidak dapat login dan sesi aktifnya dihentikan pada permintaan berikutnya. Saat mendaftar, siswa memilih sekolah terlebih dahulu lalu kelas yang hanya tersedia untuk sekolah tersebut; pilihan langsung disimpan pada akun siswa, sehingga mereka otomatis tercatat di daftar akun kelas. Server memvalidasi kecocokan sekolah dan kelas. Pengaturan kelas akun yang sudah terdaftar dikelola Admin Sekolah melalui daftar akun kelas. Pengelolaan guru serta isolasi menyeluruh data belajar antarsekolah belum tersedia.

Di Panel Admin Sekolah, daftar kelas menampilkan jumlah siswa tingkat X, XI, dan XII. Tautan **Lihat akun** membuka daftar siswa dengan filter tingkat, sehingga Admin Sekolah dapat melihat akun satu tingkat saja atau seluruhnya. Jalankan `database/migrate_student_grade_level.sql` pada database lama agar pilihan dan pemisahan tingkat aktif; siswa yang belum memilih tingkat tetap dapat dilihat melalui filter **Belum dipilih**.

Di ruang belajar, pengguna mengetik kode sendiri pada editor dan mengirimkannya untuk ditinjau admin; unggahan foto tugas tidak lagi digunakan. Setiap jalur HTML, CSS, JavaScript, PHP, dan Python memiliki 50 tahap dari fondasi sampai proyek website mini, dengan contoh yang harus diketik ulang, latihan, dan tugas yang membangun hasil sebelumnya. Penyelesaian materi baru diberikan setelah admin menyetujui kode. HTML, CSS, dan JavaScript dijalankan dalam pratinjau browser terisolasi. Python dijalankan di Web Worker menggunakan Pyodide; pertama kali perlu mengunduh runtime beberapa MB dari jsDelivr, sedangkan kode latihan tetap berada di browser dan tidak dikirim ke layanan tersebut. PHP berjalan di sisi server sehingga tidak dieksekusi oleh runner browser; jalankan hanya pada lingkungan PHP lokal yang aman dan kirim kode untuk ditinjau admin. Dari Panel Admin, Admin/Super Admin dapat mengatur visibilitas setiap kursus dengan tombol **Sembunyikan dari user** atau **Tampilkan ke user**. Kursus tersembunyi tidak muncul di katalog maupun daftar kursus dashboard, dan tidak dapat diikuti atau dibuka pengguna. Panel Admin juga menampilkan soal terakhir yang dibuka/dikerjakan beserta nomor urutnya di dalam kursus, jumlah materi disetujui, persentase progres, pengajuan yang menunggu review, serta waktu aktivitas. Kartu peninjauan praktik juga menunjukkan nomor soal dan modul agar admin mengetahui kiriman tersebut berasal dari soal ke berapa.

Setelah semua materi kursus disetujui admin, pengguna akan menerima notifikasi bahwa sertifikat tersedia. Sertifikat mencantumkan nama lengkap dari profil, nama kursus, tanggal selesai, logo CodeMif, dan tanda tangan perusahaan CodeMif. Sertifikat dapat dibuka dari Dashboard, Jelajahi Kursus, atau ruang belajar, lalu dicetak atau disimpan sebagai PDF melalui dialog cetak browser.

Tutor AI tersedia pada menu **Tutor AI Kursus** untuk kursus yang sudah diikuti. Secara default tutor memakai Ollama di komputer lokal, jadi tidak membutuhkan API key atau biaya per pertanyaan:
1. Instal dan jalankan Ollama dari https://ollama.com/download.
2. Buka PowerShell dan jalankan `& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" pull qwen2.5-coder:1.5b` untuk mengunduh model lokal. Jika perintah `ollama` sudah ada di PATH, Anda juga dapat menjalankan `ollama pull qwen2.5-coder:1.5b`.
3. Pastikan `.env` memakai `AI_PROVIDER=ollama`, `OLLAMA_BASE_URL=http://127.0.0.1:11434`, dan `OLLAMA_MODEL=qwen2.5-coder:1.5b`.
4. Aktifkan ekstensi PHP cURL dan muat ulang halaman Tutor AI.

Model berjalan di komputer sendiri dan membutuhkan RAM/ruang disk; kualitas dan kecepatannya bergantung pada perangkat. Pertanyaan beserta kutipan materi kursus dikirim ke layanan Ollama lokal di komputer tersebut, bukan OpenAI. Opsional, untuk memakai OpenAI API berbayar, ubah `AI_PROVIDER=openai` dan isi `OPENAI_API_KEY` di `.env`. Jangan masukkan API key ke kode publik.

Untuk membantu mempercepat jawaban lokal, Tutor AI hanya mengirim satu materi yang paling relevan, membatasi panjang konteks dan jawaban, meminta Ollama mempertahankan model di memori selama 10 menit, dan menampilkan jawaban secara bertahap. Model 1.5B lebih ringan dan biasanya lebih cepat daripada model 3B, tetapi kualitas jawaban dapat berkurang. Respons pertama tetap dapat lebih lambat karena model perlu dimuat ke memori.
